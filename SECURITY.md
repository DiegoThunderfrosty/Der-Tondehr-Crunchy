# Security policy

Do not publicly disclose a vulnerability that could execute code, write outside expected directories, expose private data, or load untrusted content unsafely.

Until a dedicated contact address exists, use GitHub's private **Report a vulnerability** feature if it is enabled for the repository. Include the affected version, component, minimum reproduction steps, and expected impact.

Only the latest release receives security updates. Do not attach private audio projects, recordings, credentials, tokens, personal paths, or third-party files to a report.
